# Gerenciador de Tarefas

Projeto desenvolvido durante o curso da B7Web com o professor Bonieky.

A ideia foi criar uma lista de tarefas simples, onde o usuário pode adicionar o que precisa fazer e remover os itens quando quiser.

Foi um projeto feito para praticar meus conhecimentos em HTML, CSS e JavaScript, principalmente a interação entre a página e as ações realizadas pelo usuário.

## Funcionalidades

* Adicionar tarefas
* Remover tarefas

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript

Projeto desenvolvido durante meus estudos de desenvolvimento web.
